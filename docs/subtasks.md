# Подзадачи по улучшению тестового контура

## Высокий приоритет (S)
1. Исправить расчёт `success_rate` в `scripts/run_tests.py` и покрыть формулу unit-тестом (позитивные, skipped, xfail).
2. Починить импорт конфигурации и добавить e2e-тест для CLI `library/utils/cli_tools/chunk_io_main.py`.
3. Обновить CLI `get_activities`: дефолтное значение `limit`, уважение флага `cfg.io.exist_ok`, дополнительный тест на запись выходного файла и ошибку при отсутствии директории.

## Средний приоритет (M)
4. Добавить офлайн-режим для `scripts/check_determinism.py`, обновить документацию и покрыть тестом повторяемость результата.
5. Перевести финальные логи пайплайна (`scripts/get_activity_data.py`) на структурированный формат; обновить соответствующие проверки.
6. Написать тестовый набор для клиента OpenAlex с моками успешного ответа, 404, некорректного JSON и таймаута.

## Низкий приоритет (L)
7. Доработать `prepare_io_paths` для детерминированных имён файлов или явного параметра даты; документировать политику.
8. Обновить документацию (README) с описанием офлайн-проверки детерминизма и политикой детерминированных CSV.
9. Расширить покрытие ключевых сценариев пайплайна тестами: загрузка входных CSV, нормализация, обработка пропусков, логирование, итоговая сборка, постобработка, деградационные кейсы, идемпотентность.

## Инфраструктура CI
10. Настроить публикацию `reports/test_report.json` и `reports/test_summary.md` с проверкой порога 95 % успешных тестов.
