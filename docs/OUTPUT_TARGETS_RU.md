# Постобработка изоформ мишеней

Пайплайн получения данных по мишеням теперь формирует дополнительную таблицу с
изоформами на основе основного экспорта `output.target_<date>.csv`. Логика в
точности повторяет используемый ранее Power Query (M), поэтому Python-версия
гарантирует побайтное совпадение.

## Схема этапов

1. Выбираются столбцы `isoform_synonyms`, `isoform_names`, `isoform_ids`,
   `uniprot_id_primary`, `target_chembl_id`.
2. Приведение к нижнему регистру выполняется только для `isoform_synonyms` и
   `isoform_names` (значения ID остаются без изменений).
3. Строки разбиваются по символу `|`, пробелы удаляются, пустые токены
   игнорируются.
4. Списки имён, идентификаторов и синонимов выравниваются по индексу с
   заполнением `null` там, где элементов меньше.
5. Каждый синоним разбивается по `:`; для каждого токена добавляются варианты с
   удалением подстрок `pde` и `pld`.
6. Формируются две таблицы:
   - Имена изоформ: значения после трима, без пустых строк, `n/a` и `none`.
   - Токены синонимов: плоский список вариантов с теми же фильтрами.
7. Таблицы объединяются; далее выполняются детерминированные стадии удаления
   дублей и сортировки:
   - Distinct по четырём полям (`id`, `name`, `target_chembl_id`,
     `uniprot_id_primary`).
   - Стабильная сортировка (`mergesort`) по `uniprot_id_primary`, затем `id`
     (значения `null` оказываются первыми).
   - Distinct по трём полям (`id`, `target_chembl_id`, `name`).
   - Финальный Distinct по двум полям (`id`, `name`).
8. Выгрузка выполняется строго с порядком столбцов
   `['id', 'uniprot_id_primary', 'target_chembl_id', 'name']` в кодировке UTF-8
   без BOM и с разделителем запятая.

Все шаги полностью повторяют поведение эталонного M-скрипта.

## Пример

### Вход (`output.target_20250301.csv`)

| target_chembl_id | uniprot_id_primary | isoform_names  | isoform_ids         | isoform_synonyms        |
|------------------|--------------------|----------------|---------------------|-------------------------|
| CHEMBL1000       | Q11111             | Alpha\|A       | IsoA\|IsoA-Variant  | PDE3A:alpha\|Alpha variant |
| CHEMBL1001       | Q22222             |  n/a \| none   | IsoB                |                         |
| CHEMBL1003       |                    |                | MixedID             | PLDALPHA\|pdeBeta        |

### Выход (`isoform.output.target_20250301.csv`)

| id            | uniprot_id_primary | target_chembl_id | name          |
|---------------|--------------------|------------------|---------------|
|               |                    | CHEMBL1003       | pdebeta       |
|               |                    | CHEMBL1003       | beta          |
| MixedID       |                    | CHEMBL1003       | pldalpha      |
| MixedID       |                    | CHEMBL1003       | alpha         |
| IsoA          | Q11111             | CHEMBL1000       | alpha         |
| IsoA          | Q11111             | CHEMBL1000       | pde3a         |
| IsoA          | Q11111             | CHEMBL1000       | 3a            |
| IsoA-Variant  | Q11111             | CHEMBL1000       | a             |
| IsoA-Variant  | Q11111             | CHEMBL1000       | alpha variant |

Порядок строк соответствует выгрузке. Пустые идентификаторы сохраняются, если в
источнике были имена или токены без привязки к ISO ID.

## Использование

Постобработка вызывается автоматически после выполнения команды
`python scripts/get_target_data.py all ...`. При необходимости можно запустить
её вручную:

```python
from library.postprocessing import target

target.process_targets("output.target_20250301.csv")
```

Загрузчик автоматически пробует кодировки `utf-8`, `utf-8-sig`, `cp1252` и
выводит краткий прогресс. Все операции сортировки и удаления дублей стабильны, и
повторный запуск с тем же входом даёт идентичный CSV.

## Совместимость и гарантии

- Python ≥ 3.11, pandas ≥ 2.3.
- Дополнительные зависимости не требуются.
- Экспорт строго в UTF-8 без BOM и с разделителем `,`.
- Полное совпадение с M-реализацией по значениям, порядку строк и столбцов.
