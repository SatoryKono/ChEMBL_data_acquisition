# Аномалии вывода get_target_data.py

## Ожидаемое поведение

Согласно политике стандартизации вывода каждая команда семейства `get_*_data.py` должна сохранять ровно три CSV-артефакта с помощью `save_standard_outputs`: агрегированный датасет, отчёт по корреляциям и отчёт по контролю качества. После стандартного запуска не должно оставаться никаких других файлов.

## Текущее состояние генерации артефактов

### Промежуточные выгрузки и очистка стандартного пакета

Команда `target all` и типизированный раннер `run_target_service` формируют временные CSV для стадий ChEMBL, UniProt и IUPHAR, а затем передают их в объединяющий шаг. После успешной записи финального датасета вызывается `_cleanup_intermediate_outputs`, который удаляет временные файлы, если они не были явно запрошены пользователем (например, через CLI-флаги `--chembl-out` и т.п.). 【F:library/cli/commands/get_target_data.py†L150-L167】【F:library/cli/commands/get_target_data.py†L4404-L4433】

ChEMBL-пайплайн дополнительно сохраняет canonical-набор (`output.<table>_<date>.csv` + QC/корреляционные отчёты) рядом с указанным путём. Чтобы эти вспомогательные файлы не оставались после объединения, `fetch_chembl` по умолчанию включает `_cleanup_standard_output_artifacts`, удаляющий dataset, `.meta.yaml` и связанные отчёты, сохраняя при этом основной экспорт. 【F:library/cli/commands/get_target_data.py†L170-L199】【F:library/cli/commands/get_target_data.py†L3012-L3109】【F:library/cli/commands/get_target_data.py†L4404-L4417】

### Постпроцессинг

При запуске с флагом `--postprocess` выполняется `run_target_postprocess_if_requested`. Процедура создаёт `output_postprocessed.targets.csv` и, при наличии, отчёт о шагах постобработки. Эти артефакты остаются в каталоге назначения намеренно: они дополняют основной CSV, но не заменяют его. 【F:library/cli/commands/get_target_data.py†L536-L643】

## Рекомендации по мониторингу

* Следить за журнальными событиями `target_postprocess_*`, чтобы понимать, когда в каталоге появляются постпроцессинговые выгрузки и отчёты.
* При диагностике лишних файлов проверять, не запрашивал ли пользователь сохранение промежуточных CSV: в этом случае `_cleanup_intermediate_outputs` их не удаляет.
