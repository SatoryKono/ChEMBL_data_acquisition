### Обязательные команды CI

В непрерывной интеграции всегда запускаются следующие команды (в указанном
порядке). Изменения в пайплайне должны поддерживать их успешное выполнение и
детерминированные артефакты отчётности:

1. `python scripts/run_tests.py` — pytest + генерация `reports/test_report.json`
   и `reports/test_summary.md` с проверкой порога **95 %** успешных тестов.
2. `pytest -q` — минимальный smoke-прогон без отключения предупреждений.
3. `ruff check` — статический анализ кода, ошибок форматирования и импорта.
4. `mypy --strict library` — строгая проверка типизации основной кодовой базы.
5. `pre-commit run --all-files` — консистентная обвязка локальных и CI-проверок.

## Как обновить отчёт

1. Активировать окружение: `source .venv/bin/activate`.
2. Сгенерировать отчёты:
   ```bash
   python scripts/run_tests.py
   ruff check > ruff-report.txt
   mypy --strict library > mypy-report.txt
   ```
3. Перенести обновлённые значения в эту страницу.

## Риски

- **Чанкованный CSV-писатель добавляет BOM.** Тест `tests/unit/test_chunk_io.py::test_process_csv_chunks__writes_unix_newlines` выявляет, что вспомогательный писатель теперь сохраняет BOM в результирующий файл. Это ломает downstream-пайплайн и блокирует генерацию покрытия. Требуется исследовать конфигурацию кодека/открытие файлов в `library/io/chunk.py` (или связанной обвязке) и убрать BOM при записи.【44479e†L1-L32】
- **Линтер блокируется на структуре CLI.** Синтаксические ошибки и нарушения порядка импортов в `library/cli` и связанных скриптах приводят к 90 ошибкам `ruff`, блокируя прогон `pre-commit` и мешая тестам CLI.【690c74†L1-L118】
- **Dev-зависимости конфликтуют с Python 3.11.** Пакет `types-pytest` недоступен для текущей версии интерпретатора, поэтому `pip install -r requirements-dev.txt` завершается с ошибкой; необходимо зафиксировать совместимый релиз или скорректировать список зависимостей.【145da3†L1-L12】
- **Отсутствует единая точка запуска проверок.** Команда `pre-commit run --all-files` недоступна из-за отсутствующей утилиты, что повышает риск рассинхрона между локальными и CI-проверками. Нужно закрепить установку `pre-commit` в инструкциях разработчика и CI job'е.【ee7f08†L1-L2】
