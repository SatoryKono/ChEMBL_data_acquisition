# Local setup

## Toolchain

- Python 3.11 (matching `.python-version` or CI configuration).
- `pip` with `requirements-lock.txt` for deterministic installs.
- `pre-commit` for formatting (`black`), linting (`ruff`) and import sorting.
- Optional: `direnv` or `.env` file with environment variables (`CHEMBL_DA_*`).

## Installation steps

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-lock.txt
pre-commit install
```

To work on documentation only, install `pip install -r requirements-dev.txt` to
get the linting stack without heavier dependencies.

## Repository layout essentials

| Path | Notes |
|------|-------|
| `library/` | Package code. `library/__init__.py` exposes entry points for packaging. |
| `scripts/` | CLI wrappers; each script imports `library.pipelines`. |
| `config/` | Default configuration and dictionary CSVs. Local overrides belong in `config/config.local.yaml`. |
| `tests/` | Pytest suites separated into `unit`, `integration`, `e2e`. |
| `data/input` | Sample CSVs used for smoke runs and documentation examples. |
| `reports/` | Target directory for test reports generated by CI and local runs. |

## Formatting and linting

```bash
make lint        # ruff + black --check
make typecheck   # mypy
make format      # run black and ruff --fix
```

`pre-commit` ensures the same checks run before each commit.

## Environment variables

| Variable | Purpose |
|----------|---------|
| `CHEMBL_DA_BASE_PATH` | Overrides the placeholder used in `config/config.yaml` for relative paths. |
| `CHEMBL_DA_*` | Short aliases for configuration overrides (see `library/config.py`). |
| `HTTP_PROXY` / `HTTPS_PROXY` | Proxy configuration when running behind corporate networks. |

Store sensitive values in `.env` (loaded by `python-dotenv` when present).
