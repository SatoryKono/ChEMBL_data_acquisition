# Terminology glossary

| Term | Definition |
|------|------------|
| **Action type** | Derived label describing pharmacological effect of an activity (`activation`, `inhibition`, `binding`, `PAM`, `NAM`, `triaged`, `unknown`). |
| **Allowlist** | List of permitted values enforced by activity enrichment (`activity_enrichment.action_type.allowlist`). |
| **Deterministic export** | Process of sorting rows and columns with fixed rules so that repeated runs produce byte-identical CSV files. |
| **Fallback DOI** | Additional CSV used to override DOI assignments when partner APIs do not return consistent identifiers. Enabled via `--fallback-doi-*`. |
| **Metadata sidecar** | YAML file placed next to each CSV describing configuration, hashes and timestamps. |
| **Parent molecule** | Canonical molecule used when the requested compound is a salt or has alternate forms. Populated through `_testitem/molecule_*` dictionaries. |
| **Target class** | Aggregated label produced by the modular target post-processing schema (`target_class`) that flattens ChEMBL protein classifications. |
| **Pipeline version** | Semantic version recorded in exports (`pipeline_version`) derived from `library/version.py`. |
| **QC profile** | CSV/JSON outputs generated by `analyze_table_quality` summarising completeness and pattern coverage. |
| **Run ID** | UUID assigned by `get_data.py` and propagated to logs for correlation. |
| **Smoke data** | Minimal CSV fixtures in `data/input` used for testing and documentation examples. |
| **Standard value** | Normalised numeric measurement (typically molar concentration) validated to be non-negative. |
| **Star schema** | Dimensional modelling concept referenced in the architecture docs; activities form the fact table linking documents, assays, targets and test items. |
