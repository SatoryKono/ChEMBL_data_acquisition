# Инструментарий для сбора данных ChEMBL

Это руководство представляет собой обзор утилит для загрузки, нормализации и экспорта наборов данных, полученных из ChEMBL. Используйте его как основную отправную точку для инженеров и аналитиков перед изучением подробных руководств.

## Основные возможности

- **Конвейеры для сущностей**: для документов, мишеней, анализов, активностей и тестовых образцов. Каждый конвейер обрабатывает идентификаторы из CSV, обращается к внешним API, выполняет детерминированную валидацию и создает аудируемые экспорты.
- **Оркестратор** (`get-data`): объединяет все конвейеры для сущностей с общей конфигурацией и унифицированным логированием.
- **Единый слой CLI**: с общими опциями (`--input`, `--final-out`, `--log-level`, `--config` и т.д.), опциональными "сырыми" снимками (`--raw-out`, `--raw-format`, `--id-cols`, `--no-reindex-raw`) для конвейера мишеней и точками входа, объявленными в `pyproject.toml`.
- **Триада конфигурации**: значения поступают из `config/config.yaml`, переменных окружения (с префиксом `CHEMBL_DA__`) и флагов командной строки. Опциональные файлы `.env` могут быть использованы с помощью `python-dotenv` при локальных запусках.
- **Детерминированные выходные данные**: утилиты для записи CSV фиксируют порядок строк и столбцов, прикрепляют YAML-файлы с информацией о происхождении, вычисляют хеши SHA-256 и генерируют отчеты о качестве данных для каждого запуска.
- **Инструменты для разработчиков**: строгая типизация (`mypy`), линтинг (`ruff`), форматирование (`black`), тестирование (`pytest`), анализ покрытия кода и проверки детерминизма в CI.

## Структура репозитория

| Путь | Назначение |
|------|-----------|
| `scripts/` | Обертки CLI для каждого конвейера и оркестратора `get-data`. |
| `library/` | Основные модули: HTTP-клиенты, оркестрация конвейеров, нормализация, валидация, пост-обработка, ввод-вывод и вспомогательные утилиты для метаданных. |
| `library/cli/commands/` | Точки входа для консольных скриптов, используемые установленными wheel-пакетами. |
| `library/utils/cli_tools/` | Легковесные утилиты (профилирование таблиц, кешированный обработчик для мишеней, утилиты для CSV, инструменты для сопоставления). |
| `config/` | Конфигурация YAML по умолчанию, определение схемы и встроенные словари. |
| `dictionary/` | Справочные наборы данных, используемые конвейерами (кеши UniProt, таксономии мишеней, данные для QA). |
| `data/` | Входные данные для дымовых тестов и примеры экспорта. |
| `docs/` | Документация проекта (варианты на английском `_EN.md` и русском `_RU.md`). |
| `tests/` | Модульные и интеграционные тесты, охватывающие конвейеры и вспомогательные утилиты CLI. |
| `Makefile` | Удобные цели для форматирования, тестов, упаковки и линтинга. |

## Поддерживаемые точки входа

Установка проекта (`pip install .` или `pip install dist/*.whl`) регистрирует следующие консольные скрипты. Они соответствуют модулям в `scripts/`, `library/cli/commands/` или `library/utils/cli_tools/` и принимают те же аргументы, что и их эквиваленты, запускаемые через `python -m …`.

| Консольный скрипт | Модуль | Описание |
|-------------------|--------|-------------|
| `get-data` | `scripts.get_data:main` | Последовательно запускает все конвейеры с общей конфигурацией. |
| `get-document-data` | `library.cli.commands.get_document_data:main` | Сбор и обогащение документов ChEMBL. |
| `get-target-data` | `library.cli.commands.get_target_data:main` | Агрегация мишеней из ChEMBL, UniProt и IUPHAR. |
| `get-assay-data` | `library.cli.commands.get_assay_data:main` | Экспорт метаданных анализов. |
| `get-activity-data` | `library.cli.commands.get_activity_data:main` | Экспорт нормализованных записей об активностях. |
| `get-testitem-data` | `library.cli.commands.get_testitem_data:main` | Обогащение записей о молекулах данными из PubChem. |
| `get-document-type` | `library.utils.cli_tools.get_document_type:main` | Классификация типов публикаций для задач QA. |
| `csv-utils` | `library.utils.cli_tools.csv_utils_main:main` | Вспомогательные утилиты для детерминированной пере-сериализации CSV. |
| `mapper` | `library.utils.cli_tools.mapper_main:main` | Интерактивный инструмент для сопоставления UniProt/ChEMBL. |
| `table-quality` | `library.utils.cli_tools.table_quality_main:main` | Генерация профилей качества на уровне столбцов. |
| `chunk-io` | `library.utils.cli_tools.chunk_io_main:main` | Потоковая обработка CSV-чанков с сохранением порядка. |
| `get-input-initialisation` | `library.utils.cli_tools.get_input_initialisation:main` | Объединение рабочих книг Excel для инициализации. |
| `get-activities` | `library.utils.cli_tools.get_activities:main` | Генерация синтетических записей об активностях для дымовых тестов. |
| `check-determinism` | `library.utils.cli_tools.check_determinism:main` | Сравнение хешей CSV между запусками. |

Специализированное руководство [`docs/ru/USAGE.md`](./USAGE.md) (и [`docs/en/USAGE.md`](./USAGE.md)) подробно описывает аргументы, подкоманды и продвинутые сценарии использования.

Зафиксированные зависимости находятся в `requirements-lock.txt`. Пересоздавайте файл только после изменения диапазонов в `pyproject.toml`, используя чистое виртуальное окружение и команду `pip freeze`.

```bash
python -m pip install --upgrade pip setuptools wheel
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
git clone https://github.com/SatoryKono/ChEMBL_data_acquisition.git
cd ChEMBL_data_acquisition
pip install -r requirements-lock.txt
pre-commit install
```

Пользователи wheel-пакетов могут выполнить установку с помощью `pip install chembl-data-acquisition` после публикации релиза; консольные скрипты и встроенная конфигурация размещаются в каталогах пользователя, специфичных для платформы, которые перечислены в [`docs/ru/CONFIG.md`](./CONFIG.md).

## Быстрый старт

1. **Подготовьте списки идентификаторов.** Используйте шаблоны из `data/input` (например, `document.csv`, `target.csv`, `assay.csv`, `activity.csv`, `testitem.csv`) или экспортируйте свежие списки ID из вашего хранилища данных. Более полный пример находится в `data/input/full`. Каждый конвейер ожидает один идентификатор на строку; см. [`docs/ru/DATA_SCHEMA.md`](./DATA_SCHEMA.md) для имен столбцов и обязательных заголовков.
2. **Проверьте конфигурацию.** Скопируйте `config/config.yaml`, если вам нужно переопределить лимиты API, каталоги вывода или флаги для стадий. Переопределения через переменные окружения следуют шаблону `CHEMBL_DA__SECTION__KEY`. Подробности находятся в [`docs/ru/CONFIG.md`](./CONFIG.md).
3. **Запустите конвейер.**

   ```bash
   get-document-data all \
       --input data/input/document.csv \
       --final-out output.documents_$(date +%Y%m%d).csv \
       --config config/config.yaml \
       --log-level INFO
   ```

   Добавьте `--limit 10` для дымовых тестов. Конвейер мишеней предоставляет флаги для стадий, такие как `--raw-out` и `--raw-format parquet` для "сырых" снимков.
4. **Изучите артефакты.** Каждый CSV сопровождается файлом `<name>.meta.yaml`, отчетами о качестве и (для документов) JSON-сводками. См. [`docs/ru/OUTPUT.md`](./OUTPUT.md) для форматов и рекомендаций по хранению.

## Тестирование и контроль качества

Выполняйте следующие команды перед коммитом изменений или публикацией артефактов:

```bash
pre-commit run --all-files
pip check
pytest
pytest --cov=library --cov=scripts --cov-report=term-missing
check-determinism --log-level DEBUG
```

План обеспечения качества (`docs/ru/QA_PROCESS.md` / `docs/en/QA_PROCESS.md`) документирует критерии выпуска, дымовые тесты и критерии приемки. Проверки детерминизма зависят от YAML-файлов с метаданными, поэтому держите их под версионным контролем при сравнении запусков.
