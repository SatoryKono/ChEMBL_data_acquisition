# Утилиты для получения данных из ChEMBL

Этот репозиторий содержит набор утилит на Python для извлечения, обработки и обогащения данных из базы данных ChEMBL и других связанных ресурсов в области наук о жизни, таких как UniProt, IUPHAR, PubMed и PubChem.

Вся документация поддерживается в синхронизированных английской и русской версиях.

## Ключевые особенности

- **Конвейеры данных:** Комплексные конвейеры для документов, таргетов, ассеев, активностей и тестовых образцов.
- **Оркестратор:** Высокоуровневый оркестратор (`get-data`) для последовательного запуска всех конвейеров с общей конфигурацией.
- **Единый CLI:** Согласованный интерфейс командной строки с общими флагами для ввода-вывода, конфигурации и логирования.
- **Гибкая конфигурация:** Настройка через YAML-файлы, переменные окружения и аргументы командной строки.
- **Контроль качества:** Встроенная валидация схем, детерминированная запись CSV, статический анализ и модульные тесты для обеспечения качества и воспроизводимости данных.

## Быстрый старт

1.  **Создайте виртуальное окружение и установите зависимости:**

    ```bash
    python -m venv .venv
    source .venv/bin/activate  # В Windows используйте: .venv\Scripts\activate
    pip install -r requirements-lock.txt
    ```

2.  **Инициализируйте pre-commit хуки:**

    ```bash
    pre-commit install
    ```

3.  **Изучите главный скрипт-оркестратор:**

    Запустите главный скрипт `get-data` с флагом `--help`, чтобы увидеть все доступные опции.

    ```bash
    get-data --help
    ```
