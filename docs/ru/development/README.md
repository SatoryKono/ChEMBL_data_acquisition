# Руководство разработчика

Раздел содержит инженерные материалы:

- [`LOCAL_SETUP.md`](./LOCAL_SETUP.md) — настройка окружения и инструменты.
- [`TESTING.md`](./TESTING.md) — структура тестов, политика детерминизма, отчёты.
- [`CI_CD.md`](./CI_CD.md) — рекомендации по CI/CD и контроль качества.
- [`RELEASE.md`](./RELEASE.md) — чек-лист релиза и обновления словарей.

Соблюдайте форматирование и правила из `pyproject.toml`, а также требования по
determinism, описанные в `TESTING.md`.
