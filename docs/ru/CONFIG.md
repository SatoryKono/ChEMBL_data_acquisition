# Справочник по конфигурации

## Обзор

*   Все утилиты командной строки загружают свои настройки по умолчанию из файла `config/config.yaml` в корне проекта.
*   Значения проверяются функцией `library.config.load_config`, которая вызывает `Config.model_validate` из Pydantic. Файл `config.schema.json` документирует ту же структуру для использования в инструментах, но не выполняется при запуске.
*   Настройки могут быть переопределены с помощью файла `config.local.yaml`, размещенного рядом с основной конфигурацией (включая пользовательские пути, указанные через `--config`), переменных окружения и флагов командной строки. Приоритет следующий: `config/config.yaml` < `config.local.yaml` < переменные окружения < аргументы командной строки.

## Структура `config/config.yaml`

Конфигурация сгруппирована в логические блоки. Ключи верхнего уровня объединяют настройки для внешних сервисов, локальных путей к файлам и общесистемного поведения.

| Секция | Назначение |
| --- | --- |
| `sources` | Детали подключения к внешним сервисам, таким как ChEMBL, UniProt, CrossRef, PubChem и PubMed. |
| `local` | Пути к локальным ресурсам, настройки CSV по умолчанию и рабочие книги для инициализации. |
| `system` | Логирование, политика повторных попыток, глобальное ограничение скорости запросов, профилирование качества таблиц и веса для классификации документов. |
| `activity_bounds` | Правила для вывода числовых границ из данных об активностях. |
| `activity_enrichment` | Настройки для аннотирования активностей производными метками и свойствами. |
| `testitem_molecule_enrichment` | Конфигурация для обогащения тестовых образцов данными о родительских молекулах. |

Конфиденциальные значения (токены API, личные адреса электронной почты) следует передавать через переменные окружения, а не хранить в репозитории.

Настройки путей могут ссылаться на плейсхолдер `$CHEMBL_DA_BASE_PATH`. Во время выполнения он заменяется на значение аргумента командной строки `--base-path`, переменной окружения `CHEMBL_DA_BASE_PATH` или, по умолчанию, на `~/.local/share/chembl-da`. Сокращения для домашнего каталога (`~`) раскрываются до того, как относительные пути будут разрешены относительно файла конфигурации.

## Переопределение через переменные окружения

Переменные окружения следуют шаблону `CHEMBL_DA__SECTION__SUBSECTION__KEY`. Например: `CHEMBL_DA__SOURCES__CHEMBL__API__RPS=10`.
Многие общие опции также имеют короткие псевдонимы. Обратитесь к словарю `_ALIAS_MAP` в `library/config.py` для полного и авторитетного списка всех псевдонимов.
