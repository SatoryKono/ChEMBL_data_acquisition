# Справка по конфигурации

Этот документ представляет собой исчерпывающее руководство по всем параметрам конфигурации, используемым утилитами ChEMBL Data Acquisition.

## Уровни конфигурации

Конфигурация загружается и объединяется из нескольких источников, при этом последующие источники переопределяют предыдущие. Порядок приоритета следующий:

1.  **Встроенный `config.yaml`**: Базовый файл конфигурации, расположенный по пути `config/config.yaml`.
2.  **Локальный `config.local.yaml`**: Локальный файл для переопределения, который можно разместить рядом с основным файлом конфигурации.
3.  **Переменные окружения**: Системные переменные окружения.
4.  **Аргументы CLI**: Флаги командной строки, переданные при запуске.

### Конфигурация YAML

Основная конфигурация определяется файлом `config/config.yaml`. Вы можете создать файл `config.local.yaml` для хранения локальных переопределений, что полезно для отделения личных настроек (например, API-ключей или других путей) от базовой конфигурации, контролируемой версиями.

### Переменные окружения

Любой ключ конфигурации можно переопределить с помощью переменных окружения. Имя переменной строится путем добавления префикса `CHEMBL_DA__`, объединения вложенных ключей двойным подчеркиванием (`__`) и преобразования в верхний регистр.

**Пример:**
Чтобы переопределить уровень логирования, необходимо установить следующую переменную окружения:
`export CHEMBL_DA__SYSTEM__LOG__LEVEL=DEBUG`

### Аргументы CLI

Аргументы командной строки имеют наивысший приоритет. Общие параметры, такие как `--config`, `--input` и `--log-level`, могут быть переданы напрямую. Используйте `--print-config`, чтобы увидеть итоговую, действующую конфигурацию после объединения всех уровней.

## Структура `config.yaml`

Конфигурация организована в три основных раздела:

| Раздел | Назначение |
|---|---|
| `sources` | Настройки подключения и поведения для внешних источников данных (ChEMBL, UniProt, PubChem и т.д.). |
| `local` | Пути к локальным файловым ресурсам, настройки ввода-вывода по умолчанию и расположения кэша. |
| `system` | Сквозные аспекты, такие как логирование, политики повторных сетевых запросов и глобальное ограничение скорости. |

## Подробные параметры конфигурации

### `sources`

#### `sources.chembl.api`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `chembl_base` | `https://www.ebi.ac.uk/chembl/api/data` | Базовый URL для ChEMBL REST API. |
| `timeout_connect` | `5` | Таймаут соединения в секундах. |
| `timeout_read` | `30` | Таймаут чтения в секундах. |
| `rps` | `20` | Запросов в секунду для ChEMBL API. |
| `user_agent` | `chembl-da/1.0 (mailto:chembl-data@ebi.ac.uk)` | Заголовок User-Agent. **Необходимо изменить** на реальный контактный адрес для производственного использования. |

#### `sources.chembl.pipelines.*`
Этот раздел содержит настройки для конкретных конвейеров: `activity`, `assay`, `document`, `target` и `testitem`.

| Ключ | Пример по умолчанию | Описание |
|---|---|---|
| `column` | `activity_chembl_id` | Имя колонки с идентификаторами во входном CSV. |
| `batch_size`| `50` | Количество записей, запрашиваемых в одном вызове API. |
| `timeout` | `30.0` | Таймаут запроса в секундах для этого конвейера. |
| `workers` | `1` | Количество параллельных рабочих процессов для получения данных. |
| `limit` | `null` | Максимальное количество обрабатываемых записей. |

#### Другие источники (`openalex`, `crossref`, `uniprot`, `pubchem` и т.д.)
Каждый внешний источник имеет свой собственный блок конфигурации в `sources`, определяющий его базовый URL, ограничения скорости (`rps`) и таймауты.

**Пример: `sources.pubchem`**
| Ключ | По умолчанию | Описание |
|---|---|---|
| `base` | `https://pubchem.ncbi.nlm.nih.gov/rest/pug` | Базовый URL для PubChem PUG REST API. |
| `rps` | `5` | Запросов в секунду для PubChem API. |
| `resolve_order` | `cache → smiles → inchikey → inchi → pref_name` | Порядок стратегий, используемых для поиска PubChem CID. |
| `cid_cache_path`| `.../pubchem_cid_cache.json` | Путь к постоянному кэшу PubChem CID. |

### `local`

#### `local.io`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `output_dir` | `"$CHEMBL_DA_BASE_PATH/output"` | Базовый каталог по умолчанию для всех генерируемых файлов. |
| `cache_dir` | `"~/.cache/chembl-da"` | Каталог по умолчанию для кэша HTTP-запросов. |
| `csv_sep` | `,` | Разделитель по умолчанию для чтения и записи CSV-файлов. |
| `csv_encoding`| `utf-8-sig` | Кодировка символов по умолчанию для CSV-файлов. |
| `exist_ok` | `true` | Если `true`, выходные каталоги создаются автоматически. |

#### `local.resources`
Этот раздел определяет пути к локальным файлам данных, таким как словари и таблицы сопоставления, используемые для обогащения данных.

| Ключ | Пример по умолчанию | Описание |
|---|---|---|
| `dictionary_dir` | `../config/dictionary` | Корневой каталог для всех файлов словарей. |
| `iuphar_target_csv` | `.../_IUPHAR_target.csv` | Путь к таблице сопоставления таргетов IUPHAR. |

---

### `system`

#### `system.log`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `level` | `INFO` | Уровень логирования по умолчанию. Может быть переопределен флагом `--log-level`. |

#### `system.rate`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `global_rps` | `100` | Глобальное ограничение скорости, применяемое ко всем клиентам API. |
| `global_burst` | `100` | Емкость глобального "ведра токенов" для кратковременных всплесков. |

#### `system.retry`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `max_attempts` | `3` | Количество попыток повторных сетевых запросов по умолчанию. |
| `backoff_factor`| `0.5` | Множитель, используемый для расчета задержки между повторными попытками. |
| `status_forcelist`| `[429, 500, 502, 503, 504]` | Коды состояния HTTP, которые вызывают повторную попытку. |

Для получения полного и подробного списка всех доступных опций, пожалуйста, обратитесь к исходному файлу [`config/config.yaml`](../config/config.yaml) и моделям Pydantic в [`library/config.py`](../library/config.py).
