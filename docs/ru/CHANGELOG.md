# Журнал изменений

> **Языки:** [English](../en/CHANGELOG.md) · [Русский](./CHANGELOG.md)
## [0.1.7] - 2025-10-19
- Обновлена документация и протокол по итогам PR-0…PR-8: актуализированы диаграммы пайплайна, примеры CLI с `--emit-legacy-artifacts`, описания конфигурации и двуязычный DOCX.


Все значимые изменения проекта фиксируются в этом файле.


## [0.1.7] - 2025-10-19
- Стандартизирован пайплайн целей: тонкий CLI сохраняет детерминированные CSV и
  `.meta.yaml`, а логика вынесена в модульные шаги.
- Добавлена отдельная Pandera-схема и обогащение UniProt/GtoPdb с устойчивыми
  HTTP-клиентами и структурированным логированием.
- Расширены автоматические тесты (merge, интеграция, CLI), чтобы экспорт целей
  оставался воспроизводимым.
- Добавлен специализированный модуль постобработки анализов, который
  вычисляет UTC-метки времени и календарный год напрямую из метаданных
  ChEMBL.
- Введена отдельная схема Pandera для нового ассейного экспорта и покрытие
  тестами нормализации дат и обогащения словарями.

## [0.1.6] - 2025-10-18
- Добавлены утилиты структурированного логирования с идентификатором запуска и
  длительностью этапов, а также отказоустойчивые ретраи HTTP-запросов в клиентах
  Chembl, PubChem, UniProt и Crossref.
- Перевели постобработку таблиц активностей, анализов, документов, целей и
  тестовых веществ на валидацию через Pandera с явным логированием ошибок.
- Вернули вспомогательную функцию `list_output_files`, чтобы сводка оркестратора больше не падала после успешного выполнения пайплайна.

## [0.1.5] - 2025-10-18
- Усилен оркестратор: при отсутствии ожидаемых CSV-артефактов выполнение завершается с ошибкой и перечнем найденных файлов для ускорения диагностики.
- Нормализованы байтовые пути словарных ресурсов перед преобразованием в ``Path``, чтобы статическая типизация принимала байтовые ссылки из манифеста.

## [0.1.4] - 2025-10-17
- Пересобран комплект документации после октябрьского аудита: пары README теперь
  синхронизируются автоматически, экспорт протокола в DOCX воспроизводится
  через `scripts/convert_md_to_docx.py`, а журнал изменений отражает
  утверждённую базовую версию CHEMBL-DM01/2.1.

## [0.1.3] - 2025-10-16
- Уточнена сборка иерархий: курированные связи используются в первую очередь, а при пробелах подключаются безопасные резервные источники.
- Расширено структурированное логирование уровня INFO для фиксации решений о резервировании, чтобы проще отслеживать обработку иерархий.

## [0.1.2] - 2025-10-09
- Добавлено единообразное логирование уровня INFO в `get_document_data`, `get_assay_data`, `get_testitem_data` и `get_activity_data`, чтобы отслеживать ход ETL.

## [0.1.1] - 2025-10-02
- Вся Markdown-документация из корня перенесена в каталог `docs/`, ссылки внутри файлов обновлены.
- Номер пакета повышен, чтобы отразить реорганизацию документации.

## [0.1.0] - 2025-09-28
- Первый публичный релиз.
