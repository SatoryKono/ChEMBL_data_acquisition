# Глоссарий терминов

| Термин | Определение |
|--------|-------------|
| **Action type** | Производная классификация активности (`activation`, `inhibition`, `binding`, `PAM`, `NAM`, `triaged`, `unknown`). |
| **Allowlist** | Список допустимых значений для `action_type`, задаётся в `activity_enrichment.action_type.allowlist`. |
| **Детерминированный экспорт** | Сортировка строк/колонок по фиксированным правилам для получения идентичных CSV при повторных запусках. |
| **Fallback DOI** | Дополнительный CSV с корректировками DOI, подключается через флаги `--fallback-doi-*`. |
| **Файл метаданных** | YAML, лежащий рядом с CSV и описывающий конфигурацию, хэши и временные метки. |
| **Parent molecule** | Каноническая молекула, соответствующая соли или альтернативной форме; берётся из словарей `_testitem/molecule_*`. |
| **Target class** | Агрегированная метка `target_class`, которую формирует модульная пост-обработка таргетов на основе классификаций ChEMBL. |
| **Pipeline version** | Версия пакета, записываемая в колонку `pipeline_version` (источник — `library/version.py`). |
| **QC profile** | CSV/JSON отчёты `analyze_table_quality` с метриками полноты и шаблонов. |
| **Run ID** | UUID запуска, который назначает `get_data.py` и передаёт в логи. |
| **Smoke data** | Минимальные CSV из `data/input`, используемые для тестов и примеров. |
| **Standard value** | Нормализованное числовое значение (обычно концентрация), проверяется на неотрицательность. |
| **Star schema** | Звёздная модель данных: таблица активностей выступает фактом, связующим документы, ассайи, таргеты и тестовые объекты. |
