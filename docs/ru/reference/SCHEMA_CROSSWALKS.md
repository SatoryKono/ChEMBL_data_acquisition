# Сопоставление схем

Приложение описывает, как входные колонки переходят в выходные таблицы и какие
соединения выполняются внутри конвейеров.

## Конвейер документов

| Входная колонка | Выходные колонки | Примечание |
|-----------------|------------------|------------|
| `document_chembl_id` | `document_chembl_id` | Основной ключ, передаётся через все этапы. |
| `PMID` | `pubmed_id`, `PubMed.PMID`, `scholar.PMID` | Используется при включённых стадиях `pubmed`. |
| Колонка из CSV DOI-фолбэка | `doi_normalised`, `PubMed.DOI`, `crossref.*` | Подменяет DOI, если внешние сервисы дают расхождения. |

## Конвейер таргетов

| Входная колонка | Выходные колонки | Примечание |
|-----------------|------------------|------------|
| `target_chembl_id` | `target_chembl_id` | Обязательная для всех режимов. |
| `mapping_uniprot_id` | `uniprot_id_primary` | Колонка по умолчанию для UniProt в режиме `all`. |
| `uniprot_id` | `uniprot_id_primary` | Используется, если указан `--column uniprot_id`. |
| `protein_classifications` | `target_class`, `protein_family` (представление пост-обработки) | Модульная пост-обработка разворачивает первый уровень классификации для QA-отчётов. |

### Этапы объединения

1. **ChEMBL** — агрегация метаданных и кросс-ссылок по `target_chembl_id`.
2. **UniProt** — объединение по `uniprot_id_primary`, добавление последовательностей, GO и топологии.
3. **IUPHAR** — сопоставление UniProt→IUPHAR для цепей и семейств.

## Конвейер ассайев

| Входная колонка | Выходная колонка | Примечание |
|-----------------|------------------|------------|
| `assay_chembl_id` | `assay_chembl_id` | Основной ключ. |
| `Target ID` | `target_chembl_id` | Связь с таргетом по данным ChEMBL. |

## Конвейер активностей

| Входная колонка | Выходные колонки | Примечание |
|-----------------|------------------|------------|
| `activity_chembl_id` | `activity_id` | Сохраняется без изменений. |
| `standard_type`, `standard_relation`, `standard_value`, `standard_units` | Те же колонки | Валидируются и нормализуются. |
| `action_type` | `action_type` | Пересчитывается при включённом `activity_enrichment`. |
| `activity_properties` | `activity_properties`, `properties_hash` | Формируется плоское представление и хэш. |

## Конвейер тестовых объектов

| Входная колонка | Выходные колонки | Примечание |
|-----------------|------------------|------------|
| `molecule_chembl_id` | `molecule_chembl_id` | Основной ключ. |
| `pref_name` | `pref_name` | Сохраняется, может дополняться данными PubChem. |
| `parent_molecule_chembl_id` (если есть) | `parent_molecule_chembl_id` | Перекрывает значение из словаря. |

## Взаимосвязи между таблицами

- Активности связывают документы (`document_chembl_id`), ассайи (`assay_chembl_id`),
  таргеты (через метаданные ассая) и тестовые объекты (`molecule_chembl_id`).
- Звёздная модель описана в [`architecture/DATA_MODEL.md`](../architecture/DATA_MODEL.md).

При добавлении новых колонок обновляйте таблицу соответствий, чтобы отражать
источники данных и путь до финальной выгрузки.
