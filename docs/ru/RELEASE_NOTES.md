# Примечания к релизу

> **Языки:** [English](../en/RELEASE_NOTES.md) · [Русский](./RELEASE_NOTES.md)

## Не выпущено

- Минимальная поддерживаемая версия Python уточнена как 3.11 во всей документации и проверках времени выполнения.
- Задокументировано требование указывать в `api.user_agent` контакт реального человека, описана проверка и переменная окружения `CHEMBL_DA__SOURCES__CHEMBL__API__USER_AGENT`.
- Логи попаданий и промахов кэша ChEMBL и PubChem понижены до уровня DEBUG, чтобы уменьшить шум в стандартных INFO-журналах.
- Добавлены резервные варианты для изоформ UniProt, расширено извлечение кросс-ссылок (AlphaFold, PDB, Ensembl) и логирование покрытия идентификаторов в пайплайне объединения таргетов.
- Унифицированы переопределения путей CLI: флаги `--base-path`, `--input-dir`, `--output-dir` и `--cache-dir` теперь транслируются в поля конфигурации `local.io`.
