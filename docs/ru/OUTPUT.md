# Справка по выходным данным

Этот документ описывает файлы, генерируемые конвейерами получения данных ChEMBL.

## Структура каталогов

По умолчанию все выходные файлы записываются в каталог, указанный в параметре `local.io.output_dir` вашей конфигурации (обычно `~/.local/share/chembl-da/output`).

Типичный запуск одного конвейера (например, `get-activity-data`) создаст набор связанных файлов, имеющих общее базовое имя:

```
output/
├── output.activities_20240101.csv
├── output.activities_20240101.meta.yaml
├── output.activities_20240101_failure_cases.csv
└── output.activities_20240101_quality_report_table.csv
```

---

## Основные файлы данных

### Детерминированные CSV (`*.csv`)

Основным результатом каждого конвейера является CSV-файл, содержащий обработанные данные. Эти файлы генерируются детерминированно, что означает, что при одинаковых входных данных и конфигурации выходной файл будет идентичен байт в байт. Это достигается за счет:

*   Сортировки колонок по алфавиту.
*   Сортировки строк по предопределенному ключу.
*   Использования согласованной кодировки (`utf-8-sig`) и форматирования.

---

## Метаданные и отчеты о качестве

Для каждого основного файла данных генерируется несколько сопутствующих файлов, предоставляющих метаданные, результаты валидации и метрики качества.

### Сопутствующий файл метаданных (`*.meta.yaml`)

Это самый важный сопутствующий файл. Он содержит всю необходимую информацию для воспроизведения результата, включая:

*   **`generated_at`**: Метка времени в формате ISO 8601, когда был создан файл.
*   **`git_sha`**: Хеш коммита Git кода, использованного для генерации файла.
*   **`command`**: Точная команда, которая была запущена.
*   **`config`**: Действующая конфигурация, использованная для запуска (с замаскированными секретами).
*   **`stats`**: Ключевая статистика, включая количество обработанных строк и контрольную сумму SHA-256 выходного CSV.

### Ошибки валидации (`*_failure_cases.csv`)

Если какие-либо строки из входных данных не проходят валидацию по целевой схеме (определенной с помощью Pandera), они сохраняются в этот файл для проверки. Это гарантирует, что основной выходной файл содержит только валидные данные.

### Отчеты о качестве таблиц (`*_quality_report_table.csv`)

Этот файл содержит отчет, сгенерированный `library.table_quality`, предоставляющий статистику на уровне колонок для выходных данных, такую как:

*   Количество пропущенных значений.
*   Уникальность.
*   Распределение типов данных.

### Отчет о качестве документов (`*.quality.json`)

Специально для конвейера документов этот JSON-файл предоставляет метрики по покрытию DOI и ошибкам, возникшим при получении данных из внешних сервисов публикаций.

## Ключевые колонки, добавляемые конвейерами

В процессе обработки в данные добавляется несколько стандартных колонок для облегчения отслеживания и анализа:

*   **`pipeline_version`**: Версия пакета `chembl-data-acquisition`, который был использован.
*   **`timestamp_utc`**: Метка времени UTC, когда был инициирован запуск конвейера.
*   **`lower_value` / `upper_value`**: В конвейере активностей эти колонки содержат вычисленные числовые границы для значений активности.
*   **`publication_class`**: В конвейере документов эта колонка содержит итоговую классификацию публикации (например, `review`, `experimental`).
