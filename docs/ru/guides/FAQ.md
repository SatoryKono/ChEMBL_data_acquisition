# FAQ и диагностика

Часто задаваемые вопросы по сбоям пайплайнов и способам их устранения. Английская
версия расположена в [`../../en/guides/FAQ.md`](../../en/guides/FAQ.md).

## Почему `get_document_data` завершается с ошибкой "--mode is required"?

`get_document_data` требует явного указания флага `--mode` (`chembl`, `pubmed`,
`all`). Парсер в итоге вызывает
[`prepare_io_paths`](../../../library/cli/parser.py), которому нужен режим при
формировании логов. Передайте `--mode` или используйте позиционный алиас
(`python scripts/get_document_data.py all ...`).

## Я указал `--limit 0`, но ничего не произошло. Это нормально?

Да. Все CLI интерпретируют `--limit 0` как «пропустить выполнение». Оркестратор
(`get-data`) пробрасывает это ограничение во все конвейеры, поэтому нулевое
значение удобно для проверки конфигурации без сетевых вызовов.

## Оркестратор падает с `input directory not found`. Что проверить?

`scripts/get_data.py` по умолчанию разрешает пути относительно `--base-path`.
Если CSV лежат в `data/input`, запускайте команду из корня репозитория или явно
задайте `--base-path`. Либо укажите абсолютные пути через `--input-dir`/`--output-dir`.

## Как отладить ошибки HTTP 429/5xx?

Все HTTP-клиенты находятся в `library/clients/*` и используют общую систему
ретраев. В логах ищите события `rate_limit_hit` и `retry_attempt`. Настройте
лимиты через конфигурацию (например `sources.chembl.api.rps`) или переменные
окружения (`CHEMBL_DA_RPS`). Для PubMed и партнёров убедитесь, что контактные
адреса и User-Agent содержат реальный e-mail — некоторые сервисы блокируют
анонимные запросы.

## Пайплайны ругаются на отсутствующие колонки или разделители

Валидаторы входных данных расположены в `library/schemas/input_*.py`. Сверьте
названия колонок с [`../DATA_SCHEMA.md`](../DATA_SCHEMA.md) и проверьте
разделитель/кодировку командой `file -bi <csv>`. При необходимости переопределите
флаги CLI (`--sep`, `--encoding`). Оркестратор не меняет разделители автоматически,
поэтому смешение шаблонов с разным форматом гарантированно вызовет ошибки схемы.

## Почему `action_type` принимает значение `unknown`?

`library/pipelines/activity/enrichment.py` сопоставляет метрики с действиями по
секциям `activity_enrichment.action_type.metrics` в `config/config.yaml`. Добавьте
нужные метрики в allowlist и перезапустите пайплайн. Если метрика присутствует,
но значение пустое, трансформация сознательно возвращает `unknown`, чтобы
избежать неверных догадок.

## Как пересоздать соответствия parent molecule?

Словари родителей обрабатывает модуль `library.integration.molecule_catalog`.
Запустите `python -m library.integration.molecule_catalog --help`, чтобы увидеть
доступные команды. По умолчанию данные забираются из ChEMBL и обновляют кэши
JSON/SQLite по путям из [`../reference/DICTIONARIES.md`](../reference/DICTIONARIES.md).
Конвейер тестовых объектов (`get_testitem_data`) читает эти кэши автоматически,
поэтому перед большими прогонками обновите их, если заметили расхождения.

## Проверка детерминизма показывает различия между запусками

Используйте `check-determinism --baseline <dir1> --candidate <dir2> --explain`
для сравнения хэшей. Различия только по меткам времени связаны с `.meta.yaml`.
Сфокусируйтесь на CSV, повторите прогон с теми же входными данными, seed'ами и
зависимостями. Политика детерминизма описана в
[`../development/TESTING.md`](../development/TESTING.md).

## Pytest завершился с success-rate < 95%

Скрипты отчётности читают `reports/test_report.json`, чтобы применить порог 95%,
указанный в [`../development/CI_CD.md`](../development/CI_CD.md). Откройте JSON,
найдите упавшие тесты, устраните проблему и перезапустите
`pytest --json-report --json-report-file=reports/test_report.json`. Markdown-отчёт
`reports/test_summary.md` дублирует итоговые показатели.

## Куда заносить новые проблемы?

Создайте issue с указанием проблемного пайплайна, приложите фрагменты логов и,
по возможности, обезличенный CSV. Используйте метки из
[`../development/RELEASE.md`](../development/RELEASE.md) (`data-quality`,
`client`, `determinism`) и опишите план исправления, чтобы обновления легко было
внести в changelog.
