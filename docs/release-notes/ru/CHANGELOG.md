# Журнал изменений

## [0.1.2] - 2025-10-03
- Добавлен общий помощник для CLI-логирования и настроено единое зеркалирование структурированных логов во всех скриптах извлечения данных.
- Точки входа скриптов теперь фиксируют параметры запуска, этапы выполнения и статистику обработки в согласованном формате.

## [0.1.1] - 2025-10-02
- Вся Markdown-документация из корня перенесена в каталог `docs/`, ссылки внутри файлов обновлены.
- Номер пакета повышен, чтобы отразить реорганизацию документации.
