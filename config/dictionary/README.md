# Dictionary resources

Этот каталог содержит встроенные справочники и исходные данные, которые используются пайплайнами получения данных ChEMBL в качестве локальных источников истины. Файлы лежат в структуре по сущностям (activity, document, target, testitem) и считываются из кода как статические ресурсы.

## Навигация
- [`_activity/`](./_activity/README.md) — сиды активностей ChEMBL для запуска `get_activity_data`.
- [`_document/`](./_document/README.md) — справочник публикаций для `get_document_data`.
- [`_target/`](./_target/README.md) — комбинация классификатора таргетов, выгрузок IUPHAR и кэша UniProt.
- [`_taxonomy/`](./_taxonomy/README.md) — агрегированные таксономические группы и штаммы для обогащения таблицы assay.
- [`_testitem/`](./_testitem/README.md) — сиды молекул, их иерархия и словарь тестовых веществ.

> Обновляя CSV, обязательно синхронизируйте README в соответствующей папке: укажите источник данных, схему и шаги проверки, чтобы ревьюеры могли быстро воспроизвести изменения.

## Контрольные суммы и allow-list

Обновляя словари, синхронизируйте контрольные суммы и дополнительные allow-list'ы,
иначе проверки детерминизма в CI упадут:

1. Запустите `python tools/build_dictionary_resources.py --update-checksums`,
   чтобы пересобрать `manifest.yaml` с актуальными SHA256.
2. Если наблюдается новая платформа-зависимая сумма, добавьте её в
   `manifest.allowlist.yaml` с пояснением в комментарии и, при необходимости,
   расширьте рантайм-список в `library/resources/dictionaries.py`.
3. Убедитесь, что список checksum'ов отсортирован и не содержит дубликатов.
4. Проверьте изменения командой `pytest tests/unit/test_dictionaries.py`,
   которая валидирует manifest и сопутствующие allow-list'ы.
